密钥安全

API Key 仅保存在当前浏览器的 localStorage 中，并随合成请求发送到本项目的同源代理。密钥不会被写入代码、日志，也不会提交到 Git。

免费注册获取，无需信用卡。

获取 Fish API Key ↗

固定为 s2.1-pro-free（免费档）。如需切换，请修改 server.js 中的 FISH_MODEL 常量。

MiMo TTS（备用引擎）

需要小米开放平台账号；部分地区可能需要中国手机号。

打开小米开放平台 ↗

默认 mimo-v2.5-tts。V2.5 系列部分模型已于 2026-10-21 退役；如遇模型不存在，请从小米开放平台获取当前可用 ID（可能是 V2.6 系列）。
